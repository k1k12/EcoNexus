The backend setup is trivially simple. You just need to install required python modules:
- Make sure you've created an isolated virtual environment for python, or so called "venv". If not please do so, and if you face any difficulties, use Google or ChatGPT. On windows there are multiple ways to do that, depending on whether you're using powershell or cmd, and I don't want to describe them all here (I'll have Windows flashbacks lol, **joking, just lazy**).
- Activate (source into) the virtual environment.
- Make sure you're in the backend directory and run: `python install -r requirement.txt`

Well done! You can now go back to the main readme and follow next steps.
